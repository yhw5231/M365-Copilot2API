Proxy pool
Configure outbound proxies with http / https / socks5; each account keeps its proxy node, other accounts avoid it, and on failure an unbound node is preferred, falling back to any available node

          
        

        

          

            

              
Proxy mode

              
Direct: never use the proxy pool, all requests connect directly. Loose: prefer the pool but fall back to a direct connection when no healthy proxy is available. Strict: once a pool is configured, requests must use a healthy proxy node or fail.

            

            
          

        

        

          
Add proxy

          

            
            
            

              
              
            

            
Supported formats: http:// · https:// · socks5://; usernames and passwords are supported
